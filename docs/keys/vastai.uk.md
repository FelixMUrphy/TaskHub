# Vast.ai: API-ключ для TaskHub

[English](vastai.md) · [Усі ключі](README.md)

## Навіщо він TaskHub
- **Спостереження:** ваші інстанси, їхнє навантаження, ціна, списання за останні 30 днів, баланс і кредит.
- **Дії** (лише якщо ключ їх дозволяє): Stop, Start, Reboot — з панелі, сповіщення або Telegram.
- **Видалення (destroy)** TaskHub ніколи не робить сам. Воно можливе лише в панелі TaskHub, після введення назви.

## Мінімальні дозволи
| Потрібно | Дозволи |
|---|---|
| (a) Лише спостерігати | `instance_read`, `user_read`, `billing_read` |
| (b) Stop / Start / Reboot | те саме + `instance_write` |

Застереження: `instance_write` у Vast.ai охоплює «створення, керування та знищення інстансів і томів» — окремого
дозволу на stop / start без destroy немає. TaskHub ніколи не знищує інстанси сам, лише з панелі після введення назви.

## Створити ключ
**У консолі:** відкрийте розділ **Keys** у консолі Vast.ai → **API Keys** → **+New**. У вікні введіть назву
(наприклад, `TaskHub`) і виберіть дозволи — за замовчуванням вибрано всі дозволи облікового запису, тож залиште
лише ті, що в таблиці. Створіть ключ і скопіюйте його.

**Через CLI:** сторінки Vast.ai про дозволи описують обмежені ключі через CLI / API — скористайтеся цим, якщо
консоль не дає їх звузити. Збережіть як `perms.json`:

```json
{
    "api": {
        "instance_read": {},
        "user_read": {},
        "billing_read": {}
    }
}
```

Для дій додайте `"instance_write": {}`, потім виконайте:

```
vastai create api-key --name "TaskHub" --permission_file perms.json
```

## Вставити в TaskHub
1. TaskHub → **Налаштування** → **Конектори** → **Vast.ai**.
2. Увімкніть, вставте ключ, натисніть **Зберегти**.
3. Має з’явитися **Під’єднано, баланс …** (або **Під’єднано**). Якщо Vast.ai не прийме ключ, нічого не збережеться.

TaskHub один раз (а далі щодня) перевіряє, чи може ключ виконувати дії, і показує кнопки лише тоді, коли може.

## Де зберігається ключ
- Лише в диспетчері облікових даних Windows (Credential Manager) — ніколи в `config.json`.
- Надсилається лише на `console.vast.ai`.

## Відкликати
- **У Vast.ai:** консоль → **Keys** → **Delete** біля ключа (**Reset** замінює його новим).
- **У TaskHub:** Налаштування → Конектори → Vast.ai → **Видалити** (стирає ключ із диспетчера облікових даних).
