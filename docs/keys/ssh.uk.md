# SSH: як налаштувати хост для TaskHub

## Що TaskHub робить
- TaskHub запускає вбудований у Windows `ssh.exe` і читає кожен хост зі списку: навантаження, пам'ять, диски, GPU, сесії tmux і процес, який ви вкажете.
- **TaskHub не зберігає ні ключів, ні паролів.** Він бере ваші `~/.ssh/config`, агент SSH і `known_hosts` і лише читає їх.
- На хост нічого не встановлюється і там нічого не змінюється. Поки що підтримуються хости Linux.

## Перед тим як додати хост
TaskHub не може відповідати на запитання, тож три речі мають працювати без них.

1. **Клієнт OpenSSH.** TaskHub використовує той, що вбудований у Windows, а не копію з Git. У терміналі `C:\Windows\System32\OpenSSH\ssh.exe -V` має показати версію. Якщо ні: Параметри Windows → Система → Додаткові компоненти (у Windows 10: Програми → Додаткові компоненти) → додайте *OpenSSH Client* ([інструкція Microsoft](https://learn.microsoft.com/en-us/windows-server/administration/openssh/openssh_install_firstuse)).
2. **Ключ без введення пароля.** Ключ із парольною фразою має бути в агенті. У PowerShell від імені адміністратора, один раз:
   ```powershell
   Get-Service ssh-agent | Set-Service -StartupType Automatic
   Start-Service ssh-agent
   ```
   Потім від свого імені: `ssh-add`. ([Посібник Microsoft про ключі](https://learn.microsoft.com/en-us/windows-server/administration/openssh/openssh_keymanagement).) Агенти 1Password чи Pageant працюють, якщо обслуговують OpenSSH для Windows.
3. **Ключу хоста є довіра.** Підключіться один раз із термінала: `ssh my-server`. Звірте показаний відбиток із тим, що дав власник хоста, і відповідайте `yes`. Сам TaskHub ніколи не довіряє новому ключу.

Перевірка: `C:\Windows\System32\OpenSSH\ssh.exe -o BatchMode=yes my-server uname -s` показує `Linux` без жодних запитань.

Назву хоста записують у `~/.ssh/config` разом із користувачем, портом і ключем:
```
Host my-server
    HostName 203.0.113.10
    User me
    IdentityFile ~/.ssh/id_ed25519
```

## Додайте його
Налаштування → *Конектори* → *SSH* → увімкніть, введіть `my-server` і натисніть *Додати*. Лише літери, цифри, крапки, дефіси й підкреслення: `user@host` записують у config.

## Що ви побачите
Для кожного хоста окрема задача з його навантаженням і дисками. Сповіщення приходить, коли диск заповнюється, зникає зв'язок або TaskHub мусить припинити спроби, хост перезапускається або завершується робота:
- **сесія tmux** або команда в ній, після якої знову показується оболонка (закритий редактор теж рахується; перемикач у Налаштуваннях вимикає ці сповіщення, а в журналі задачі вони лишаються);
- **процес, який ви вкажете:** *Стежити за процесом* у задачі хоста, з його номером (наприклад, `pgrep -f train`).

TaskHub не знає, чим завершилася робота, тому пише «завершився», а не «успішно». Поки ваш ПК вимкнений, ніхто не стежить. Про завершення вказаного вами процесу буде сказано під час наступного з'єднання. Зміни в tmux і перезапуск хоста помітні лише після втраченого зв'язку, поки TaskHub працює: не після перезапуску TaskHub чи ПК.

## Що варто знати
- **Ваш config виконується.** `ProxyCommand` чи `Match exec` із `~/.ssh/config` запускаються під час кожного з'єднання TaskHub, так само як у вас у терміналі. Хости за `ProxyJump` використовують налаштування вашого config для проміжного хоста.
- **Що лишається відкритим.** Один `ssh` на хост, поки конектор увімкнено. Він надсилає фіксований скрипт лише для читання, типово щохвилини (не частіше ніж раз на 30 секунд).
- **Змінений ключ зупиняє роботу.** Якщо ключ хоста зміниться, TaskHub не підключиться й скаже про це. Це може бути перевстановлений хост або хтось посередині: перевірте й виправте `known_hosts` самі.
- **Невдалі входи.** Після відхиленого ключа TaskHub не пробує знову, доки ви не натиснете *Перевірити знову*, тож вашу адресу він не заблокує.
- **Що залишає ваш ПК.** Лише на ваші хости: ім'я користувача й публічні ключі (як у будь-якого ssh) та скрипт. Те, що повертається, лишається в папці даних TaskHub і показується у сповіщеннях, зокрема в Telegram чи Discord, якщо вони ввімкнені. Див. [PRIVACY.md](../../PRIVACY.md).

## Як зупинити
Вимкніть конектор або приберіть хост: з'єднання завершиться. На хості нічого не лишається, а в TaskHub немає ключа, який треба видаляти.
