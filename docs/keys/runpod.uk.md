# Runpod: API-ключ для TaskHub

[English](runpod.md) · [Усі ключі](README.md)

## Навіщо він TaskHub
- **Спостереження:** ваші поди, їхнє навантаження, ціна, скільки вже витрачено (білінг Runpod), баланс і на скільки його вистачить.
- **Дії** (лише якщо ключ їх дозволяє): Stop, Start, Restart — з панелі, сповіщення або Telegram.
- **Видалення** TaskHub ніколи не робить сам. Воно можливе лише в панелі TaskHub, після того як ви введете назву пода.

## Створити ключ
1. Відкрийте консоль Runpod: <https://console.runpod.io/user/credentials>.
2. У розділі **API Keys** натисніть **Create API Key**.
3. Введіть назву (наприклад, `TaskHub`) і виберіть тип (див. нижче).
4. Натисніть **Create** і одразу скопіюйте ключ — його показують лише один раз; Runpod його не зберігає.

## Який тип вибрати
| Потрібно | Тип | Примітки |
|---|---|---|
| (a) Лише спостерігати | **Read Only** | Рекомендовано, якщо кнопки не потрібні. Runpod не документує, чи може ключ Read Only читати білінг і баланс; якщо TaskHub не показує баланс — причина в цьому. |
| (b) Stop / Start / Restart | **All** | Обмеження **Restricted** Runpod документує лише для Serverless endpoints, не для подів — тож для дій із подами потрібен **All**. |

TaskHub один раз (а далі щодня) перевіряє, чи може ключ виконувати дії, і показує кнопки лише тоді, коли може.
Ключ типу **All** дозволяє й видаляти поди — TaskHub ніколи не робить цього сам, лише з панелі після введення назви.

## Вставити в TaskHub
1. TaskHub → **Налаштування** → **Конектори** → **Runpod**.
2. Увімкніть, вставте ключ, натисніть **Зберегти**.
3. Має з’явитися **Під’єднано, баланс …** (або **Під’єднано**). Якщо Runpod не прийме ключ, нічого не збережеться.

## Де зберігається ключ
- Лише в диспетчері облікових даних Windows (Credential Manager) — ніколи в `config.json`.
- Надсилається лише на `api.runpod.io` (REST для подів, розмірів мережевих томів і білінгу, GraphQL для балансу).

## Відкликати
- **У Runpod:** <https://console.runpod.io/user/credentials> → значок кошика біля ключа → **Revoke Key**
  (або вимкніть ключ перемикачем).
- **У TaskHub:** Налаштування → Конектори → Runpod → **Видалити** (стирає ключ із диспетчера облікових даних).
  Видалення TaskHub теж його стирає.
