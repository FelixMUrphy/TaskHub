# zh-CN

## Description

TaskHub 把电脑上耗时较长的任务集中到一处，并让你直接控制它们：视频导出、渲染、构建、备份、模型训练，以及 AI 编程助手替你运行的脚本。

工作方式
程序或脚本通过 127.0.0.1 上的本地 HTTP API、taskhub 命令或随附的 Python 客户端向 TaskHub 报告进度。TaskHub 随后显示：
• 托盘图标，带进度环和活动任务数；
• 面板，列出每个任务的进度、剩余时间、状态和日志，以及任务请求的小组件：折线图、面积图、柱状图、仪表、数值、指示灯、表格；
• 任务自带的控件：按钮，数字、文本或列表输入，暂停、停止和强制结束。你的选择会发回给任务；
• 任务完成、失败或停止汇报时的 Windows 通知；如果任务需要，通知中也带有它的按钮。

“taskhub run -- <命令>”可以包装任意命令行：把输出写入任务日志，从中读取进度，并添加“停止”和“结束”按钮。

Claude Code 和 Codex
在托盘菜单（AI 助手）中可以把 TaskHub 连接到 Claude Code 和 Codex。助手获得 TaskHub 工具（MCP），用来报告它的长任务；当助手完成回复或需要你的许可时，你会收到通知。TaskHub 会把自己的条目写入助手的设置文件，关闭该选项时再将其移除。

Telegram（可选）
连接你自己的 Telegram 机器人，就能在手机上收到同样的通知，并在那里点按任务按钮。消息从你的电脑直接发送到 Telegram 的 Bot API。

隐私
无需账户，没有云服务，没有遥测。API 只监听 127.0.0.1，任务和设置保存在 %APPDATA%\TaskHub。

须知
• 更新通过 Microsoft Store 提供。
• 可在托盘菜单或“设置 → 应用 → 启动”中关闭开机自启。
• API 文档可从托盘菜单打开（API 文档）。
• 需要 Windows 10 1809 或更高版本（x64）以及 Microsoft Edge WebView2 Runtime（当前的 Windows 已自带）。
• 界面语言：英语、乌克兰语、西班牙语、德语、法语、意大利语、葡萄牙语、波兰语、简体中文、日语。

## Product features

- 托盘图标，带进度环和活动任务数
- 面板为每个任务显示进度、剩余时间、日志、图表、仪表和表格
- 由任务自己声明的按钮和输入框：暂停、停止、修改参数、强制结束
- 任务完成、失败或卡住时的 Windows 通知，带任务按钮
- 本地 HTTP API、taskhub 命令行和 Python 客户端；“taskhub run”可包装任意命令
- Claude Code 和 Codex：TaskHub 工具（MCP）和通知，可在托盘菜单中开启
- 可选 Telegram 机器人：在手机上接收通知、进度并使用任务按钮
- 无需账户，无云端，无遥测；API 只监听 127.0.0.1
- 10 种界面语言

## Short description

查看并控制电脑上耗时较长的任务：进度、图表、通知以及任务自带的按钮。可通过本地 API 或 taskhub 命令配合任意脚本使用，也支持 Claude Code 和 Codex。
