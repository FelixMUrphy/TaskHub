# uk-UA

## Description

TaskHub збирає в одному місці довгі задачі на вашому ПК і дає ними керувати: експорт відео, рендери, збірки, резервні копії, навчання моделей, запуски CI, хмарні GPU-машини і скрипти, які запускають для вас AI-агенти для програмування.

Як це працює
Програма чи скрипт повідомляє TaskHub про свій прогрес через локальний HTTP API на 127.0.0.1, команду taskhub або Python-клієнт, що йде в комплекті. TaskHub показує:
• значок у треї з кільцем прогресу й кількістю активних задач;
• панель, де для кожної задачі видно прогрес, час до завершення, статус, журнал і віджети, які задача просить: лінійні, площинні й стовпчикові графіки, індикатори, показники, таблиці;
• власні елементи керування задачі: кнопки, поля для числа, тексту чи вибору зі списку, паузу, зупинку й завершення. Ваш вибір повертається до задачі;
• сповіщення Windows, коли задача завершилась, впала або перестала звітувати, з кнопками задачі, якщо вона їх просить.

«taskhub run -- <команда>» обгортає будь-який командний рядок: передає вивід у журнал задачі, бере з нього прогрес і додає кнопки «Зупинити» та «Завершити».

Налаштування в панелі
Усе налаштовується на одній сторінці: кнопка ⚙ у панелі (або «Налаштування» в меню трею) відкриває вигляд, сповіщення й Telegram, конектори, AI-агентів, автозапуск і довідку з API. У меню трею лишаються швидкі дії: відкрити панель, вимкнути сповіщення, налаштування, підтримка, вихід.

Claude Code і Codex
У «Налаштування → AI-агенти» TaskHub можна підключити до Claude Code і Codex. Агент отримує інструменти TaskHub (MCP), щоб повідомляти про свої довгі задачі, а ви — сповіщення, коли агент закінчив відповідь або чекає на ваш дозвіл. TaskHub додає свої записи у файли налаштувань агентів і прибирає їх, коли ви вимикаєте цю опцію.

Конектори (за бажанням, типово вимкнені)
• GitHub Actions: запуски workflow у вказаних вами репозиторіях як задачі: прогрес за jobs і кроками, крок, що впав, і кінець його журналу, кнопки скасування й перезапуску.
• Runpod і Vast.ai: ваші GPU-машини як задачі: GPU, ціна за годину, скільки вже витрачено, час роботи, SSH, графіки навантаження, попередження «GPU простоює», баланс і на скільки його вистачить з попередженням про низький баланс, зупинка / запуск / перезапуск (видалення — лише в панелі, після введення назви машини).
Кожен конектор працює лише після того, як ви його ввімкнете й введете власний API-ключ. Ключ зберігається тільки в диспетчері облікових даних Windows, а конектор звертається лише до API свого сервісу (api.github.com, api.runpod.io, console.vast.ai).

Захист балансу (за бажанням, вимкнений, доки ви його не ввімкнете)
Для Runpod і Vast.ai: попередження на вашому порозі балансу, а на порозі зупинки запущені машини зупиняються після сповіщення з кнопками «Зупинити зараз» і «Відкласти». Він лише зупиняє машини й ніколи їх не видаляє; якщо баланс не вдається прочитати, нічого не зупиняється.

Telegram (за бажанням)
Підключіть власного Telegram-бота, щоб отримувати ті самі сповіщення на телефоні, живе повідомлення з прогресом для кожної задачі, і натискати кнопки задач звідти. Токен бота зберігається в диспетчері облікових даних Windows, а повідомлення йдуть з вашого ПК прямо в Bot API Telegram.

Конфіденційність
Без акаунта, без телеметрії. API слухає лише 127.0.0.1, а задачі й налаштування зберігаються в %APPDATA%\TaskHub. Нічого не залишає ваш ПК, доки ви не ввімкнете Telegram або конектор.

Корисно знати
• Оновлення надходять із Microsoft Store.
• Автозапуск можна вимкнути в «Налаштування → Система» або в «Параметри Windows → Програми → Автозавантаження».
• Довідка з API відкривається зі сторінки налаштувань.
• Потрібні Windows 10 версії 2004 або новіша (x64) і Microsoft Edge WebView2 Runtime, який уже є в сучасній Windows.
• Мови інтерфейсу: англійська, українська, іспанська, німецька, французька, італійська, португальська, польська, китайська (спрощена), японська.

## Short description

Стежте за довгими задачами на ПК і керуйте ними: прогрес, графіки, сповіщення та власні кнопки задачі. Працює з будь-якими скриптами через локальний API чи команду taskhub, із Claude Code і Codex, а за бажанням — із GitHub Actions, Runpod і Vast.ai.
