# uk-UA

## Description

TaskHub збирає в одному місці довгі задачі на вашому ПК і дає ними керувати: експорт відео, рендери, збірки, резервні копії, навчання моделей і скрипти, які запускають для вас AI-агенти для програмування.

Як це працює
Програма чи скрипт повідомляє TaskHub про свій прогрес через локальний HTTP API на 127.0.0.1, команду taskhub або Python-клієнт, що йде в комплекті. TaskHub показує:
• значок у треї з кільцем прогресу й кількістю активних задач;
• панель, де для кожної задачі видно прогрес, час до завершення, статус, журнал і віджети, які задача просить: лінійні, площинні й стовпчикові графіки, індикатори, показники, таблиці;
• власні елементи керування задачі: кнопки, поля для числа, тексту чи вибору зі списку, паузу, зупинку й завершення. Ваш вибір повертається до задачі;
• сповіщення Windows, коли задача завершилась, впала або перестала звітувати, з кнопками задачі, якщо вона їх просить.

«taskhub run -- <команда>» обгортає будь-який командний рядок: передає вивід у журнал задачі, бере з нього прогрес і додає кнопки «Зупинити» та «Завершити».

Claude Code і Codex
У меню трею (AI-агенти) TaskHub можна підключити до Claude Code і Codex. Агент отримує інструменти TaskHub (MCP), щоб повідомляти про свої довгі задачі, а ви — сповіщення, коли агент закінчив відповідь або чекає на ваш дозвіл. TaskHub додає свої записи у файли налаштувань агентів і прибирає їх, коли ви вимикаєте цю опцію.

Telegram (за бажанням)
Підключіть власного Telegram-бота, щоб отримувати ті самі сповіщення на телефоні й натискати кнопки задач звідти. Повідомлення йдуть з вашого ПК прямо в Bot API Telegram.

Конфіденційність
Без акаунта, без хмарного сервісу, без телеметрії. API слухає лише 127.0.0.1, а задачі й налаштування зберігаються в %APPDATA%\TaskHub.

Корисно знати
• Оновлення надходять із Microsoft Store.
• Автозапуск можна вимкнути в меню трею або в «Параметри → Програми → Автозавантаження».
• Довідка з API відкривається з меню трею, пункт «API (довідка)».
• Потрібні Windows 10 версії 1809 або новіша (x64) і Microsoft Edge WebView2 Runtime, який уже є в сучасній Windows.
• Мови інтерфейсу: англійська, українська, іспанська, німецька, французька, італійська, португальська, польська, китайська (спрощена), японська.

## Product features

- Значок у треї з кільцем прогресу й кількістю активних задач
- Панель із прогресом, часом до завершення, журналом, графіками, індикаторами й таблицями для кожної задачі
- Кнопки й поля, які оголошує сама задача: пауза, зупинка, зміна параметра, завершення
- Сповіщення Windows про завершення, помилку й зависання, з кнопками задачі
- Локальний HTTP API, команда taskhub і Python-клієнт; «taskhub run» обгортає будь-яку команду
- Claude Code і Codex: інструменти TaskHub (MCP) і сповіщення, вмикаються з меню трею
- Telegram-бот за бажанням: сповіщення, прогрес і кнопки задачі на телефоні
- Без акаунта, без хмари, без телеметрії; API працює лише на 127.0.0.1
- 10 мов інтерфейсу

## Short description

Стежте за довгими задачами на ПК і керуйте ними: прогрес, графіки, сповіщення та власні кнопки задачі. Працює з будь-якими скриптами через локальний API чи команду taskhub, а також із Claude Code і Codex.
