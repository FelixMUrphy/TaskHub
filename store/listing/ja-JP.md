# ja-JP

## Description

TaskHub は、PC で動いている時間のかかる処理を一か所にまとめ、そこから操作できるようにするアプリです。動画の書き出し、レンダリング、ビルド、バックアップ、モデルの学習、そして AI コーディングエージェントが代わりに実行するスクリプトに対応します。

しくみ
プログラムやスクリプトは、127.0.0.1 のローカル HTTP API、taskhub コマンド、または付属の Python クライアントで TaskHub に進捗を報告します。TaskHub が表示するもの:
• 進捗リングと実行中のタスク数を示すトレイアイコン
• 各タスクの進捗、残り時間、状態、ログと、タスクが指定したウィジェット(折れ線・面グラフ・棒グラフ、ゲージ、数値、ランプ、表)を並べたパネル
• タスク独自の操作: ボタン、数値・テキスト・リストの入力欄、一時停止、停止、強制終了。選んだ内容はタスクに返されます
• タスクの完了・失敗・応答停止を知らせる Windows 通知(タスクが求めればボタン付き)

「taskhub run -- <コマンド>」は任意のコマンドラインを包み込み、出力をタスクのログに流し、そこから進捗を読み取り、停止と終了のボタンを追加します。

Claude Code と Codex
トレイメニュー(AI エージェント)から TaskHub を Claude Code や Codex に接続できます。エージェントは TaskHub のツール(MCP)で長い処理を報告でき、エージェントが応答を終えたときや許可を求めているときには通知が届きます。TaskHub はエージェントの設定ファイルに自分の項目を追加し、オプションをオフにすると削除します。

Telegram(任意)
自分の Telegram ボットを接続すると、同じ通知をスマートフォンで受け取り、そこからタスクのボタンを押せます。メッセージは PC から Telegram の Bot API へ直接送られます。

プライバシー
アカウント不要、クラウドサービスなし、テレメトリなし。API は 127.0.0.1 だけで待ち受け、タスクと設定は %APPDATA%\TaskHub に保存されます。

補足
• 更新は Microsoft Store から配信されます。
• 自動起動はトレイメニュー、または「設定 → アプリ → スタートアップ」でオフにできます。
• API リファレンスはトレイメニュー(API リファレンス)から開けます。
• Windows 10 バージョン 1809 以降(x64)と Microsoft Edge WebView2 Runtime が必要です(最新の Windows には含まれています)。
• 表示言語: 英語、ウクライナ語、スペイン語、ドイツ語、フランス語、イタリア語、ポルトガル語、ポーランド語、中国語(簡体字)、日本語。

## Product features

- 進捗リングと実行中のタスク数を示すトレイアイコン
- タスクごとに進捗、残り時間、ログ、グラフ、ゲージ、表を表示するパネル
- タスク自身が定義するボタンと入力欄: 一時停止、停止、パラメーター変更、強制終了
- 完了・失敗・停滞を知らせる Windows 通知(タスクのボタン付き)
- ローカル HTTP API、taskhub コマンド、Python クライアント。「taskhub run」で任意のコマンドに対応
- Claude Code と Codex: TaskHub のツール(MCP)と通知をトレイメニューからオン
- 任意の Telegram ボット: 通知、進捗、タスクのボタンをスマートフォンで
- アカウント不要、クラウドなし、テレメトリなし。API は 127.0.0.1 のみ
- 10 の表示言語

## Short description

PC で時間のかかる処理を見守り、操作できます。進捗、グラフ、通知、そしてタスク独自のボタン。ローカル API や taskhub コマンドで任意のスクリプトに対応し、Claude Code と Codex にも対応します。
