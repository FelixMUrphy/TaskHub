# ja-JP

## Description

TaskHub は、PC で動いている時間のかかる処理を一か所にまとめ、そこから操作できるようにするアプリです。動画の書き出し、レンダリング、ビルド、バックアップ、モデルの学習、CI の実行、クラウドの GPU マシン、そして AI コーディングエージェントが代わりに実行するスクリプトに対応します。

しくみ
プログラムやスクリプトは、127.0.0.1 のローカル HTTP API、taskhub コマンド、または付属の Python クライアントで TaskHub に進捗を報告します。TaskHub が表示するもの:
• 進捗リングと実行中のタスク数を示すトレイアイコン
• 各タスクの進捗、残り時間、状態、ログと、タスクが指定したウィジェット(折れ線・面グラフ・棒グラフ、ゲージ、数値、ランプ、表)を並べたパネル
• タスク独自の操作: ボタン、数値・テキスト・リストの入力欄、一時停止、停止、強制終了。選んだ内容はタスクに返されます
• タスクの完了・失敗・応答停止を知らせる Windows 通知(タスクが求めればボタン付き)

「taskhub run -- <コマンド>」は任意のコマンドラインを包み込み、出力をタスクのログに流し、そこから進捗を読み取り、停止と終了のボタンを追加します。

パネルの設定ページ
設定はすべて 1 ページにまとまっています。パネルの ⚙ ボタン(またはトレイメニューの「設定」)から、外観、通知と Telegram、コネクタ、AI エージェント、自動起動、API リファレンスを開けます。トレイメニューにはクイック操作(パネルを開く、ミュート、設定、サポート、終了)だけが残ります。

Claude Code と Codex
「設定 → AI エージェント」から TaskHub を Claude Code や Codex に接続できます。エージェントは TaskHub のツール(MCP)で長い処理を報告でき、エージェントが応答を終えたときや許可を求めているときには通知が届きます。TaskHub はエージェントの設定ファイルに自分の項目を追加し、オプションをオフにすると削除します。

コネクタ(任意、既定はオフ)
• GitHub Actions: 指定したリポジトリの workflow の実行をタスクとして表示。ジョブとステップごとの進捗、失敗したステップとそのログの末尾、キャンセルと再実行のボタン。
• Runpod と Vast.ai: GPU マシンをタスクとして表示。GPU、時間あたりの料金、これまでの費用、稼働時間、SSH、負荷グラフ、「GPU アイドル」の警告、残高と残り稼働時間(残高不足の警告付き)、停止 / 起動 / 再起動(削除はパネルでマシン名を入力した場合のみ)。
各コネクタは、オンにして自分の API キーを入力したときだけ動作します。キーは Windows 資格情報マネージャーにだけ保存され、コネクタは自分のサービスの API(api.github.com、api.runpod.io、console.vast.ai)とだけ通信します。

残高ガード(任意、オンにするまでオフ)
Runpod と Vast.ai 向け: 自分で決めた残高のしきい値で警告し、停止しきい値では「今すぐ停止」と「スヌーズ」付きの通知のあと、稼働中のマシンを停止します。マシンを停止するだけで、削除は決してしません。残高を読み取れない場合は何も停止しません。

Telegram(任意)
自分の Telegram ボットを接続すると、同じ通知とタスクごとのリアルタイムの進捗メッセージをスマートフォンで受け取り、そこからタスクのボタンを押せます。ボットのトークンは Windows 資格情報マネージャーに保存され、メッセージは PC から Telegram の Bot API へ直接送られます。

プライバシー
アカウント不要、テレメトリなし。API は 127.0.0.1 だけで待ち受け、タスクと設定は %APPDATA%\TaskHub に保存されます。Telegram やコネクタをオンにしない限り、PC の外には何も送られません。

補足
• 更新は Microsoft Store から配信されます。
• 自動起動は「設定 → システム」、または Windows の「設定 → アプリ → スタートアップ」でオフにできます。
• API リファレンスは設定ページから開けます。
• Windows 10 バージョン 2004 以降(x64)と Microsoft Edge WebView2 Runtime が必要です(最新の Windows には含まれています)。
• 表示言語: 英語、ウクライナ語、スペイン語、ドイツ語、フランス語、イタリア語、ポルトガル語、ポーランド語、中国語(簡体字)、日本語。

## What's new in this version

TaskHub 2.9
• パネルに設定ページ(⚙)を追加: すべての設定を一か所に。トレイメニューは Windows 11 スタイルのクイック操作だけに。
• 新しいコネクタ(既定はオフ): GitHub Actions(workflow の実行、キャンセルと再実行)、Runpod と Vast.ai(GPU マシン、費用、残高、GPU アイドルの警告、停止と起動)。API キーは Windows 資格情報マネージャーにだけ保存されます。
• Runpod と Vast.ai 向けの残高ガード(オンにするまでオフ): 設定したしきい値で警告し、停止しきい値で稼働中のマシンを停止します。削除は決してしません。
• Telegram: ボットのトークンを Windows 資格情報マネージャーに移動。メッセージを取りこぼさず、Telegram の送信ペースに合わせます。
• カードの透明度の設定を追加。ファイルやフォルダーへのリンクはエクスプローラーで表示し、実行はしません。
• 2.9.1: 金額を小数点以下 2 桁で表示、Runpod の network volume のストレージ費用を表示。
• Windows 10 バージョン 2004 以降が必要になりました。

## Product features

- 進捗リングと実行中のタスク数を示すトレイアイコン
- タスクごとに進捗、残り時間、ログ、グラフ、ゲージ、表を表示するパネル
- タスク自身が定義するボタンと入力欄: 一時停止、停止、パラメーター変更、強制終了
- 完了・失敗・停滞を知らせる Windows 通知(タスクのボタン付き)
- ローカル HTTP API、taskhub コマンド、Python クライアント。「taskhub run」で任意のコマンドに対応
- すべての設定をパネルの 1 ページに(⚙)。トレイメニューにはクイック操作
- Claude Code と Codex: TaskHub のツール(MCP)と通知を設定からオン
- 任意の GitHub Actions コネクタ: workflow の実行をタスクとして表示、キャンセルと再実行
- 任意の Runpod / Vast.ai コネクタ: GPU マシン、費用、残高、GPU アイドルの警告、停止と起動
- 任意の残高ガード: 残高不足を警告し、稼働中のマシンを停止(削除はしない)
- 任意の Telegram ボット: 通知、進捗、タスクのボタンをスマートフォンで
- アカウント不要、テレメトリなし。API キーは Windows 資格情報マネージャーのみ。API は 127.0.0.1 のみ
- 10 の表示言語

## Short description

PC で時間のかかる処理を見守り、操作できます。進捗、グラフ、通知、そしてタスク独自のボタン。ローカル API や taskhub コマンドで任意のスクリプトに対応し、Claude Code と Codex、さらに任意で GitHub Actions、Runpod、Vast.ai にも対応します。
